# MaterialDX基盤 UIプロトタイプ

## 概要

MaterialDX基盤の画面遷移とUIのイメージを確認するためのプロトタイプアプリです。
実際のバックエンド機能は実装されていませんが、画面遷移とUIの動作を体験できます。

## 特徴

- **対話型UI**: 材料探索のための自然言語インターフェース
- **Fine-Tune UI**: モデル最適化のための専用インターフェース
- **ダッシュボード**: 統合ビューで全体概要を確認
- **画面遷移**: 両UI間のシームレスな連携を体験

## 起動方法

### 方法1: ブラウザで直接開く

1. `index.html` をブラウザで開く
2. すぐに使用開始できます

### 方法2: ローカルサーバーで起動（推奨）

```bash
# ui-prototypeディレクトリに移動
cd ui-prototype

# Pythonの場合
python -m http.server 8000

# Node.jsの場合
npx http-server -p 8000

# ブラウザで開く
open http://localhost:8000
```

## 使い方

### 1. 対話型UI（デフォルト画面）

**体験できること:**
- チャット形式のインターフェース
- タスクの進捗表示
- 結果の表示（3秒後に自動表示）
- 精度が低い場合の改善提案

**操作手順:**
1. ページを開くと対話型UIが表示されます
2. 3秒後に分析結果が自動表示されます
3. 「🔧 Fine-Tuneを開始」ボタンをクリック
4. Fine-Tune UIに遷移します（コンテキストが引き継がれます）

### 2. Fine-Tune UI

**体験できること:**
- モデル選択画面
- 学習進捗のリアルタイム表示
- メトリクス（Loss、Accuracy）の更新
- 完了後の新モデルテスト

**操作手順:**
1. 対話型UIから「🔧 Fine-Tuneを開始」をクリック
2. モデル選択画面が表示されます
3. 「次へ →」ボタンをクリック
4. 学習進捗が自動的に更新されます（シミュレーション）
5. 「完了をシミュレート」ボタンで完了画面へ
6. 「対話型UIで試す →」ボタンで対話型UIに戻ります

### 3. ダッシュボード

**体験できること:**
- 対話型UIとFine-Tune UIの統計
- モデル精度の推移（プレースホルダー）
- 最近のアクティビティ

**操作手順:**
1. ナビゲーションバーの「📊 ダッシュボード」をクリック
2. 統合ビューが表示されます

### 4. 履歴

**体験できること:**
- 履歴画面のレイアウト（コンテンツは未実装）

## 画面遷移フロー

### パターン1: 対話型UI → Fine-Tune UI

```
対話型UI
  ↓ 「Fine-Tuneを開始」ボタン
Fine-Tune UI（モデル選択）
  ↓ 「次へ」ボタン
Fine-Tune UI（学習中）
  ↓ 「完了をシミュレート」ボタン
Fine-Tune UI（完了）
```

### パターン2: Fine-Tune UI → 対話型UI

```
Fine-Tune UI（完了）
  ↓ 「対話型UIで試す」ボタン
対話型UI（新モデル適用）
```

## 主要な機能

### 通知システム

画面遷移時やアクションの完了時に、右上に通知が表示されます。

- **青色**: 情報通知
- **緑色**: 成功通知
- **オレンジ色**: 警告通知

### コンテキストの引き継ぎ

画面遷移時に、以下の情報が引き継がれます（シミュレーション）:

- 対話型UI → Fine-Tune UI: モデルとデータの自動選択
- Fine-Tune UI → 対話型UI: 新モデルの自動適用

### レスポンシブデザイン

モバイルデバイスでも確認できます。

```
## 新機能: 最適化パラメーター設定（v2.0）

Fine-Tune UIに最適化パラメーター設定機能が追加されました。

### パラメーター設定画面

ステップ2として、モデル選択後にパラメーター設定画面が表示されます：

#### 🎯 最適化目標
- **最適化対象**: 精度、損失関数、F1スコア、バランス型から選択
- **目標精度**: 80-99%の範囲で設定可能

#### ⚙️ 学習パラメーター
- **学習率**: 0.0001-0.1の範囲（推奨: 0.001-0.01）
- **バッチサイズ**: 16, 32, 64, 128から選択
- **エポック数**: 10-500の範囲で設定

#### 🔧 Decision Optimization設定
- **最適化手法**: 
  - CPLEX（高精度）
  - 遺伝的アルゴリズム（バランス）
  - 勾配降下法（高速）
  - ベイズ最適化（効率的）
- **制約条件**: なし、リソース制約、時間制約、カスタムから選択
- **使用CPUコア数**: 1-32コア（IBM Cloud CPU）

#### 📊 データ設定
- **学習データ比率**: 60-90%（スライダーで調整）
- **検証データ比率**: 5-30%（スライダーで調整）
- **データ拡張**: チェックボックスで有効/無効

### リアルタイムサマリー

パラメーター変更時に、以下の情報がリアルタイムで更新されます：

- 選択した最適化手法
- 目標精度
- 推定実行時間
- 使用リソース（IBM Cloud CPU コア数）

### 使用方法

1. Fine-Tune UIのステップ1でモデルを選択
2. 「次へ」ボタンをクリック
3. パラメーター設定画面で各項目を設定
4. サマリーで設定内容を確認
5. 「🚀 最適化を開始」ボタンをクリック
6. 学習進捗画面に遷移

```

## カスタマイズ

### 色の変更

`style.css` の以下の部分を編集:

```css
/* プライマリカラー */
.header {
    background-color: #1976d2;  /* ここを変更 */
}

.btn-primary {
    background: #1976d2;  /* ここを変更 */
}
```

### 学習進捗の速度変更

`script.js` の以下の部分を編集:

```javascript
trainingInterval = setInterval(() => {
    trainingProgress += 5;  // この値を変更（大きいほど速い）
    // ...
}, 1000);  // この値を変更（ミリ秒）
```

## 制限事項

このプロトタイプは画面遷移とUIのイメージ確認を目的としており、以下の機能は実装されていません:

- 実際のAI/ML処理
- バックエンドとの通信
- データの永続化
- ユーザー認証
- 実際のモデルのFine-Tune
- グラフの描画（Chart.jsなどで実装可能）
