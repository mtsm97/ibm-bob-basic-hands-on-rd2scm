# FAQ サイト 仕様書

## 基本情報

- **種別**: 新規作成
- **目的**: qa.md の内容を使った日本語 FAQ サイトの作成
- **制約**: バックエンドなし、5分程度で完成可能な実装

## 機能要件

### 1. FAQ 表示機能

#### 1.1 カテゴリー別表示
- 以下の4つのカテゴリーで FAQ を分類表示する：
  - **一般** (General): Bob の基本情報、動作原理、機能概要、データ制約、リスク
  - **使い方** (Usage): タスク開始、モード切替、ツール、コンテキストメンション、コマンド実行、フィードバック、カスタマイズ、自動承認
  - **高度な機能** (Advanced Features): MCP、カスタム MCP サーバー
  - **トラブルシューティング** (Troubleshooting): 応答なし、変更の取り消し

#### 1.2 質問と回答の表示
- 各カテゴリー内に質問を一覧表示
- 質問は日本語で表示
- 回答は初期状態では非表示（折りたたみ）
- 質問をクリックすると回答が展開される
- 再度クリックすると回答が折りたたまれる（アコーディオン UI）

#### 1.3 表示内容
qa.md の全16項目を日本語化して表示：

**一般（5項目）**
1. Bob とは何ですか？
2. Bob はどのように動作しますか？
3. Bob は何ができますか？
4. Bob で処理してはいけないデータ型はありますか？
5. Bob を使用するリスクは何ですか？

**使い方（8項目）**
1. 新しいタスクを開始するには？
2. モードを切り替えるには？
3. ツールとは何ですか？どのように使用しますか？
4. コンテキストメンションとは何ですか？
5. Bob はターミナルでコマンドを実行できますか？
6. Bob にフィードバックを提供するには？
7. Bob の動作をカスタマイズできますか？
8. Bob に自動承認設定はありますか？

**高度な機能（2項目）**
1. MCP（Model Context Protocol）とは何ですか？
2. 独自の MCP サーバーを作成できますか？

**トラブルシューティング（2項目）**
1. Bob が応答しません。どうすればよいですか？
2. Bob が望まない変更を行いました。元に戻すには？

### 2. 検索機能

#### 2.1 検索対象
- 質問テキスト
- 回答テキスト
- 両方を対象に部分一致検索

#### 2.2 検索動作
- ヘッダーに検索バーを配置
- リアルタイム検索（入力中に結果を更新）
- 検索語に一致する質問・回答のみを表示
- 一致しない項目は非表示
- 検索語が空の場合は全項目を表示
- 大文字小文字を区別しない

#### 2.3 検索結果の表示
- 一致した項目のカテゴリーも表示
- 一致項目がない場合は「該当する FAQ が見つかりませんでした」と表示

### 3. レスポンシブデザイン

#### 3.1 対応デバイス
- デスクトップ（1024px 以上）
- タブレット（768px - 1023px）
- スマートフォン（767px 以下）

#### 3.2 レイアウト調整
- デスクトップ: 2カラムレイアウト可能
- タブレット: 1カラムレイアウト
- スマートフォン: 1カラムレイアウト、フォントサイズ調整

## 確認方法

### 1. 機能確認
1. ブラウザで index.html を開く
2. 全カテゴリーと質問が表示されることを確認
3. 各質問をクリックして回答が展開/折りたたみされることを確認
4. 検索バーに「Bob」と入力し、関連する FAQ のみが表示されることを確認
5. 検索バーをクリアし、全 FAQ が再表示されることを確認

### 2. レスポンシブ確認
1. ブラウザの開発者ツールを開く
2. デバイスモードで以下のサイズを確認：
   - iPhone SE (375px)
   - iPad (768px)
   - Desktop (1920px)
3. 各サイズでレイアウトが適切に調整されることを確認

### 3. ブラウザ互換性確認
1. Chrome で動作確認
2. Firefox で動作確認
3. Safari で動作確認（Mac の場合）
4. Edge で動作確認

### 4. パフォーマンス確認
1. ページ読み込み時間を確認
2. 検索の応答速度を確認
3. アコーディオンのアニメーションがスムーズか確認

## 想定される課題とリスク

### 1. 技術的課題
- **課題**: 検索機能のパフォーマンス
- **対策**: FAQ 数が少ないため問題なし（16項目）

### 2. UI/UX 課題
- **課題**: 長い回答の表示
- **対策**: スクロール可能な領域として表示

### 3. 保守性
- **課題**: FAQ の追加・更新
- **対策**: data.js ファイルにデータを集約し、更新を容易にする
